# Skills

A skill is a procedure a bot can run again. A bot's Description holds the durable rules. A skill holds the steps.
One home per kind of information:
| Kind | Home |
|---|---|
| Job rules | The bot's Description |
| Today's task | The chat or the task card |
| A procedure | A skill in this folder |
| Timing | A routine |
| Team rules | `AGENTS.md` (one shared file) |
| Prices, features, facts that change | The live source. Do not copy them. |

Format: one folder per skill, one `SKILL.md` with a short front matter. See `example-skill/SKILL.md`.
